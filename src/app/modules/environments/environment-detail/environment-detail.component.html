    Context

    The context is the shared environment of the whole site: values like outdoor temperature or working hours that every zone and every formula can read (as context.<key>). Static entries keep their value until changed on the Live state tab; driven entries follow a day cycle or replay a recorded series on their own.

    Static values

    A static entry is a fixed fact about the site that sources can read, e.g. energy_price = 0.32 or floor_area = 1200. A formula reads it as context.energy_price. It only changes when you edit it here or on the Live state tab.

    No static values yet. Add one when several formulas should share a fact about the site.

    Driven values

    A driven value changes on its own instead of staying fixed, e.g. outdoor temperature warming up over the afternoon or a season replayed from a real recording. Zones and formulas read it exactly like a static value.

    No driven values yet.

    Initial States

    What this zone starts with when the simulation boots, e.g. temperature = 20. Sensors and formulas in this zone read these values; scripts can change them while the simulation runs. This is not the current live value -- see the Live state tab for that.

    Time Constants (seconds)

    How sluggishly this zone follows a change, in seconds per value. Example: a time constant of 1800 for temperature means a heating step needs about 30 minutes until two thirds of it show in the value. Leave a key out for one that should jump instantly instead.
